🧘‍♀️ YogaBloom — Yoga Course Landing Page
A modern, responsive landing page designed to help users find and choose their ideal yoga course. The project combines aesthetic design with functionality to attract and convert new practitioners.

✨ Key Features
Course Catalog: Three courses for each level from beginner to pro.
Interactive Selection: User-friendly navigation to find the course that fits you best.
Lead Generation Form: A seamless way to leave contact details for a manager’s consultation.
Fully Responsive: Optimized for a smooth experience across Mobile, Tablet, and Desktop.
Smooth Animations: Gentle transitions to maintain a calm and harmonious atmosphere.

🛠 Tech Stack
HTML5 / SCSS: Semantic markup with a modular style structure.
JavaScript: Logic for course selection and form validation.
Vite: Fast project bundling and development server.
GitHub Pages: Hosting for the live demonstration.

🚀 Getting Started
To run this project locally, follow these steps in your terminal:
Clone the repository:
Bash
git clone https://github.com/Serhii-Panov/Project-team-12.git
Install dependencies:
Bash
npm install
Start the development server:
Bash
npm start
